## 1. Pembuatan Logika Skor (`lib/scoring.ts`)
Buat file `lib/scoring.ts` yang berisi fungsi murni `hitungSkor`. Fungsi ini tidak boleh memanggil database atau API eksternal. Gunakan rumus berikut secara ketat[cite: 30, 31]:

**Parameter Input:**
`pagu`, `penawaran`, `tenagaTotal`, `tenagaLokal`, `durasi`, `durasiMin`, `durasiMax`, `kelengkapan` (0-5), `syaratLokalMin` (default 70).

**Rumus Komponen (0-100):**
*   **Efisiensi Biaya (Bobot 40%):**
    *   `r = penawaran / pagu`.
    *   Jika `r > 1`: Lempar error (penawaran ditolak).
    *   Jika `0.80 <= r <= 0.95`: Skor 100.
    *   Jika `0.95 < r <= 1.00`: Turun linear dari 100 ke 70.
    *   Jika `r < 0.80`: Skor `100 - ((0.80 - r) * 250)`, minimal 0.
    *   *Flag:* Jika `r < 0.70`, tambahkan flag "perlu klarifikasi harga".
*   **Serapan Tenaga Lokal (Bobot 30%):**
    *   Skor = `100 * (tenagaLokal / tenagaTotal)`.
    *   *Flag:* Jika persentase di bawah `syaratLokalMin`, tambahkan flag "di bawah syarat".
*   **Rasionalitas Jadwal (Bobot 20%):**
    *   Jika `durasiMin <= durasi <= durasiMax`: Skor 100.
    *   Jika `durasi < durasiMin`: Skor `100 - 15 * (durasiMin - durasi) / durasiMin`.
    *   Jika `durasi > durasiMax`: Skor `100 - 100 * (durasi - durasiMax) / durasiMax` (minimal 0).
*   **Kelengkapan Dokumen (Bobot 10%):**
    *   Skor = `100 * (kelengkapan / 5)`.

**Hasil Akhir:**
*   `total` = `Math.round((0.40 * biaya) + (0.30 * lokal) + (0.20 * jadwal) + (0.10 * lengkap))`
*   Kembalikan object: `{ total, rincian: { biaya, lokal, jadwal, lengkap }, flags, versiBobot: "v1" }`[cite: 31]

## 2. Pembuatan Unit Test (`__tests__/scoring.test.ts`)
Buat file tes menggunakan `Vitest` untuk menguji skenario T01. Konfigurasi dasarnya adalah Pagu = Rp100.000.000, `durasiMin` = 30, `durasiMax` = 60, `syaratLokalMin` = 70. 
Pastikan tes memvalidasi 3 proposal ini[cite: 31]:
*   **Proposal A:** Penawaran 88jt, Tenaga 10/9 (Lokal 9), Durasi 45, Lengkap 4. **Ekspektasi Total: 95**, tanpa flag.
*   **Proposal B:** Penawaran 99jt, Tenaga 12/6 (Lokal 6), Durasi 25, Lengkap 3. **Ekspektasi Total: 66**, Flag: "tenaga lokal di bawah syarat".
*   **Proposal C:** Penawaran 62jt, Tenaga 8/8 (Lokal 8), Durasi 40, Lengkap 5. **Ekspektasi Total: 82**, Flag: "perlu klarifikasi harga".
